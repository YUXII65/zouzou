# 新用户一次性提示全量梳理

> 整理日期：2026-09-24  
> 范围：首次进入、新手期、一次性引导、一次性页内提示。  
> 不包含：普通空状态、错误提示、落地页演示、游客常驻横幅。

## 当前状态（2026-09-24 调整后）

已暂停：

- `/welcome` 四步首次欢迎引导
- 注册、登录、游客入口不再强制经过欢迎页，直接进入首页

仍然启用：

- Web 主界面的 4 步锚定轻引导（第 4 步是抽屉复盘）
- 抽屉页、工具匣页的一次性页内提示
- 新手期图标展开文字
- 小程序独立的四步新手引导
- AI 偏好提示代码仍在，但由于欢迎页已停用，新注册用户通常不会再写入触发所需的本地标记

## 一、当前新用户路径

### Web 注册 / 登录路径

1. 注册或登录成功后直接进入首页
2. 应用内锚定引导第 1 步：开始记录想法
3. 任务出现后进入第 2 步：推进任务
4. 第 3 步：使用便利贴
5. 首组任务完整收尾后进入第 4 步：抽屉复盘

### 小程序路径

1. 登录成功后检查 `first_run_tour`
2. 首次用户进入独立的四步新手引导页
3. 第 4 步包含抽屉复盘
4. 完成后进入今日页或书桌页

## 二、状态与记忆位置

| 标记 | 作用 | 位置 |
| --- | --- | --- |
| `first_run_tour` | 服务端权威进度：1 / 2 / 3 / 4 / done | 用户偏好 |
| `next_step_tour` | 导航或气泡展示的本地缓存进度 | localStorage |
| `next_step_new_user` | 兼容旧逻辑的新手标记 | localStorage |
| `next_step_hints` | 页内提示是否关闭 | localStorage |
| `next_step_ai_question_asked` | 用户第一次提交 AI 想法 | localStorage |
| `next_step_ai_pref_hint_dismissed` | AI 偏好提示是否关闭 | localStorage |

服务端判定是否仍处于新手期：

- `first_run_tour != done`
- 账号注册不超过 14 天
- 项目数不超过 1，且任务数不超过 3；或者引导已经进行到 2/3/4

## 三、已暂停：欢迎页四步引导

位置：`/welcome`  
入口：正常注册 / 登录后首次进入。

### 顶部跳过

- 按钮：跳过
- 结果：完成 onboarding，但轻引导进度设为 1，之后仍会出现轻量引导。

### 游客体验提示

- 显示条件：游客进入欢迎页。
- 标题：游客体验中
- 正文：注册正式账号后，这个体验里的内容可以继续保存。
- 操作：注册保存

### 步骤 1：写想法

- 标题：写想法
- 输入框示例：比如：整理自己的个人网站
- 辅助操作：示例想法、换一批
- 主按钮：下一步

### 步骤 2：谈感受

- 标题：谈感受
- 表单：AI 生成的 2-4 个选择维度
- 主按钮：下一步
- 补充输入：允许写自己的想法或卡点

### 步骤 3：建项目

- 标题：建项目
- 展示：你最初说：{原始想法}
- 字段：项目名、目标、里程碑
- 主按钮：下一步
- 降级提示：暂时连不上，先用本地整理，结果可继续修改。

### 步骤 4：定今日

- 标题：定今日
- 字段：今日任务
- 主按钮：完成，去书桌查看

## 四、Web 统一四步新手引导

位置：首页 / 书桌页  
组件：锚定气泡，高亮真实按钮，不做全屏蒙层。  
总步骤：4 步。

### 第 1 步：记录想法

- 首页锚点：快速记录输入区
- 书桌兜底锚点：日历导航
- 标题：先从一句话开始 / 先回日历记一个想法
- 结果：进入第 2 步

### 第 2 步：推进任务

- 锚点：任务行的“下一步”按钮；没有任务时指向日历导航
- 标题：把任务推起来 / 先把想法变成一条任务
- 正文：点击【下一步】推进任务，一次只推进一个完整动作
- 结果：进入第 3 步

### 第 3 步：使用便利贴

- 锚点：任务行便利贴按钮
- 标题：使用便利贴
- 正文：点一下【便利贴】，AI 会为你写一张详细执行步骤。你也可以补充自己的想法或卡点。
- 结果：进入第 4 步，并等待首组任务完整收尾

### 第 4 步：抽屉复盘

- 显示条件：首组任务已完成至少一条，没有待办或进行中任务，且还没有复盘
- 锚点：抽屉 / 复盘导航
- 标题：抽屉复盘
- 正文：首组任务已完成。点左侧【抽屉】，用复盘留下今天的判断和明天的方向。
- 主操作：去复盘
- 次操作：稍后
- 结果：完成整套 4 步引导

## 五、复盘引导

复盘已经并入 Web 4 步引导的第 4 步，不再使用独立的复盘提示组件。

## 六、页内一次性提示

### 抽屉页

- 组件：右下角 / 移动端底部的普通提示卡。
- 显示条件：新手期，或者用户还没有任何复盘。
- 标题：提示
- 正文：每日复盘，并给出明天的执行建议
- 关闭方式：点关闭按钮，或点击卡片外区域。
- 记忆：按页面 id 记为已关闭。


## 七、AI 偏好一次性提示

位置：首页“偏好设置”折叠区里的 AI 偏好表单上方。  
触发条件：

1. 本地存在 `next_step_new_user=1`
2. 用户已经提交过一次 AI 想法
3. 用户没有关闭过该提示

文案：

- 标题：说明你的偏好
- 正文：下一次整理，结果会更准。

关闭后不再展示。

当前风险：该提示依赖本地新手标记；如果用户绕过欢迎页，或者本地数据被清理，提示可能不出现。另外它嵌在折叠区内，默认折叠时用户未必能看到。

## 八、新手期的非弹窗提示

新手期内，任务行右侧的图标会展开为“图标 + 文字”：

- 便利贴按钮显示文字：便利贴
- 首页和书桌页都使用同一新手期条件
- 引导结束后自动收起为图标

## 九、小程序四步新手引导

位置：小程序独立引导页。  
展示条件：`isFirstRun && tourStep != done`。

1. 先从一句话开始
2. 推进任务
3. 使用便利贴
4. 抽屉复盘：完成一组任务后，点「抽屉」留一次复盘，记下今天的判断和明天的方向。

其他：

- 底部显示 1 / 4 到 4 / 4
- 完成后写入 `first_run_tour=done`

## 十、暂不纳入，但和新人体验有关

- 游客常驻横幅：游客模式提示和“注册并保存”入口，不是一次性关闭。
- 首页空状态：今天还没有重点，先记录一个想法。
- 项目空状态：还没有项目、当前没有推进中的任务。
- 落地页演示和 `/onboarding` 演示页：属于体验入口，不是严格的新手指引。
- 错误、配额、AI 不可用等运行态提示。

## 十一、当前可讨论的重复与冲突

1. 欢迎页四步引导已停用，后续只保留应用内的一套 4 步引导。
2. Web 和小程序第 2 步文案仍需最后统一。
3. 抽屉页和工具匣页仍使用普通角落提示卡，没有指向真实目标，也没有统一到锚定气泡体系。
4. AI 偏好提示依赖本地新用户标记，但欢迎页停用后，新注册用户通常不会触发。
5. 小程序第 4 步目前是顺序展示的复盘说明，Web 第 4 步等待首组任务完成后再出现。
