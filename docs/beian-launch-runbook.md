## 为什么必须做这一步

微信小程序的 `wx.request` 只允许**已 ICP 备案**的域名。`nextstep9.work` 现在没备案，
真机上请求会被微信拦掉（`urlCheck: false` 只对开发者工具有效）。
所以：备案 → 域名可用 → 小程序才能提交审核上线。

## 第一段：域名 ICP 备案（腾讯云）

### 1. 先停解析 ⚠️

**首次备案（新增备案）期间，域名不能有任何解析。** 这是管局要求，不是可选项。

DNSPod 控制台 → 域名解析 `nextstep9.work` → 删除这两条记录：

- `nextstep9.work` 的 CNAME → `nextstep9.work.pages.dnsoe5.com`
- `www` 的 CNAME → `www.nextstep9.work.pages.dnsoe5.com`

> 先删再提交。否则腾讯云初审会让你关站重来，白等一轮（1-2 个工作日）。
> 代价：这段时间 `https://nextstep9.work` **打不开**，约 7-12 天。
> EdgeOne Pages 的默认域名在中国大陆返回 401，顶不上，别指望它当过渡入口。

### 2. 提交备案

<https://console.cloud.tencent.com/beian> → 开始备案 → 备案资源选**云服务器**（选中那台上海 CVM）

要准备的信息：

- 主体：姓名、身份证号、手机号、邮箱、证件住址
- 网站：网站名称、域名 `nextstep9.work`、服务内容
- 证件：身份证正反面照片
- 核验：**微信扫码做人脸识别**（这一步只能本人做，agent 代不了）

网站名称建议填「走走个人工作台」这类带个人属性的名字。个人备案不能用
「XX公司」「XX网」等字样，提交时系统会校验，被驳回只改这一项即可。

### 3. 等审核

| 阶段 | 时长 |
| --- | --- |
| 腾讯云初审 | 1-2 个工作日 |
| 管局审核（上海市） | 5-10 个工作日（全国最快梯队） |

初审通过后会有**短信核验**，一般 24 小时内不核验订单会失效。收到短信第一时间点。

## 第二段：备案通过后（恢复上线）

### 4. 恢复解析

DNSPod 把两条 CNAME 加回去，值同上。等 DNS 生效 + EdgeOne 重新签发证书。

**验证方式**：抓首页 HTML 里的 CSS 地址，带个查询串请求一次，返回 `200 + text/css` 才算资源就绪。
如果页面裸 HTML 无样式，通常是发布窗口的 404 被浏览器缓存了，强刷即可。

### 5. 配置小程序服务器域名

微信公众平台 → 小程序 → 开发管理 → 开发设置 → 服务器域名 → request 合法域名
加入 `https://nextstep9.work`（不要带路径）。保存后即时生效。

### 6. 小程序备案（独立流程，别和域名备案混为一谈）

2023 年 9 月起微信小程序必须完成备案才能上架。入口在微信公众平台
（设置 → 基本设置 → 小程序备案，或首页顶部提示），同样要上传证件 + 人脸核验。

### 7. 提交审核

微信开发者工具打开 `miniprogram/` → 上传 → 填版本号和备注 → 公众平台提交审核。

上传前确认主包体积：微信主包上限 2 MB。**当前实测 395.3 KB**，余量充足。
以后往 `miniprogram/` 放整屏图片前先算体积，别再塞 PNG 大图。

审核还要选**服务类目**。「走走」是效率工具类，别选到需要前置审批的类目。
如果收集用户信息，记得在微信公众平台配置《用户隐私保护指引》。
