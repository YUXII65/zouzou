这是一个单机使用的 AI 个人项目推进系统，核心闭环是：

`输入 -> 收件箱 -> 整理 -> 项目/任务 -> 今日执行 -> 复盘`

本教程按“你第一次打开系统后，应该先做什么、每天怎么用”来写。

## 1. 打开系统

本地开发服务启动后，浏览器访问：

```text
http://localhost:3000
```

系统有 3 个一级页面：

| 页面 | 地址 | 用途 |
| --- | --- | --- |
| 日历 | `/` | AI 任务生成、今日待办 |
| 书桌 | `/workspace` | 管理项目、任务和待办来源 |
| 抽屉 | `/review` | 生成每日复盘草稿，修改后保存 |

今日页把 AI 任务生成放在最前面：你输入一个任务，AI 拆成项目和待办，一键生成后进入今日待办。桌面端使用左侧导航，移动端使用底部导航。系统没有登录注册，是本地单用户工作台。

## 2. 第一次使用：先建立项目

不要一上来就录入大量任务，先把长期目标组织成项目。

1. 进入“项目”页。
2. 在“新建项目”表单里填写：
   - 项目名称：例如“下一步”。
   - 项目目标：这个项目希望达成什么结果。
   - 状态：进行中。
   - 当前里程碑：例如“完成 Stage 2”。
   - 项目备注：补充背景、约束或下一步安排。
3. 点击“创建项目”，会自动定位到该项目，并在右侧看到项目详情和任务。

在“项目”页中，展开项目后你可以：

- 在“快捷新增任务”里直接给这个项目创建任务。
- 查看该项目下的所有任务。
- 修改项目名称、目标、状态、里程碑和备注。
- 删除项目。注意：删除项目后，项目下的任务会保留，但不再关联该项目。

## 3. 随时记录：快速放入收件箱

系统最重要的习惯是“先记录，再整理”。

在“今日”页的“AI 任务生成”区域输入一个任务：

```text
下周完成首页设计和移动端适配
```

点击“记录并交给 AI”，系统会自动生成整理结果。

这里的关键原则是：记录动作很轻，不需要立刻决定它属于哪个项目、什么时候完成。

## 4. 处理收件箱：从零散输入变成正式内容

进入“今日”页的“AI 任务生成”区域，输入任务后会直接看到 AI 拆分结果。

### 4.1 使用 AI 整理

如果旧记录还没有计划，可以点击“AI 整理”。

AI 会给出：

- 是否新建项目，或归入已有项目。
- 项目目标、当前里程碑。
- 1-5 条任务计划。
- 每条任务的优先级和日期。
- 计划理由。

计划只是草稿，不会自动写入正式业务数据。你确认后点击“确认创建计划”，系统会一次创建项目和多条任务。

如果未配置 DeepSeek Key，或 AI 调用失败，系统会使用本地规则生成基础建议，手动流程不受影响。

### 4.2 手动处理

每条待处理记录都可以手动选择：

- `转为任务`：直接把原内容作为任务标题创建任务，不需要额外编辑标题。
- `忽略`：不会进入任务或项目。

表单字段包括：

- 所属项目。
- 优先级。
- 截止日期。

点击“转为任务”后，记录会进入“已处理”列表；点击“忽略”后进入“已忽略”列表。

如果这条内容不重要，可以直接点击“忽略”，不需要填写表单。

## 5. 管理任务

任务在“项目”页管理：每个项目都可以展开，任务直接显示在项目下面。

创建任务时建议填写：

- 任务标题：一个清晰、可执行的动作。
- 备注：补充上下文或验收信息。
- 所属项目：尽量挂到项目下，避免任务散落。
- 优先级：低、中、高、紧急。
- 计划日期：计划在哪一天执行。
- 截止日期：最晚完成时间。
- 今日重点日期：标记为哪一天的重点任务。

在任务列表里可以：

- 编辑任务。
- 标记完成。
- 取消任务。
- 重新打开。
- 删除任务。

已完成和已取消的任务不会进入“今日”页的未完成任务统计，也不会再出现在 AI 今日建议里。

## 6. 今日执行

打开“今日”页，系统会按这些维度组织当天工作：

- 顶部统计：进行中项目、未完成任务、待处理收件箱、今日复盘。
- 今日重点：`focusDate` 为今天的任务。
- 逾期任务：过了截止日期仍未完成的任务。
- 今天计划：`scheduledDate` 为今天的任务。
- AI 今日建议：从未完成任务中推荐 1-3 条重点。

### 6.1 设置今日重点

在今日页的“AI 今日建议”或任务操作区，点击“设为今日重点”。

设置后，任务会出现在“今日重点”区域，适合用来锁定当天最重要的 1-3 件事。

如果不再需要，点击“取消今日重点”即可。

### 6.2 完成任务

在“今日重点”“逾期任务”“今天计划”或“AI 今日建议”里，都可以直接点击“完成”。

系统会记录完成时间。之后进入“复盘”页生成复盘时，当天完成的任务会被统计进去。

## 7. 每日复盘

进入“复盘”页：

1. 选择复盘日期，默认是今天。
2. 点击“生成 AI 复盘草稿”。
3. 系统会根据当天完成的任务、今日计划、未完成任务和项目状态生成：
   - 当天总结。
   - 下一步建议，每行一条。
4. 检查草稿内容，手动修改后点击“保存复盘”。

复盘保存前状态是“草稿”，保存后是“已保存”。
保存复盘时，系统会把“下一步建议”自动创建为任务，并默认安排到第二天。它们会出现在“今日”页的计划中，形成闭环。

历史复盘会按日期展示在左侧列表中。每条记录都可以展开“编辑复盘”再次修改。

复盘页在没有 DeepSeek Key 时也能使用：AI 不可用时系统会用本地规则生成基础草稿，或者你也可以完全手动填写。

## 8. 数据备份

所有数据保存在本地 SQLite 文件：

```text
prisma/dev.db
```

推荐每天或每周备份一次。

### 方式一：页面导出

桌面端左侧边栏底部有“导出数据备份”，点击后可以直接下载一份数据库文件。

### 方式二：命令行备份

在项目根目录执行：

```bash
pnpm db:backup
```

备份文件会写入 `backups/` 目录。

### 方式三：查看数据库

```bash
pnpm db:studio
```

这会打开 Prisma Studio，方便直接查看项目、任务、收件箱和复盘记录。

## 9. 配置 AI（可选）

系统在未配置 AI Key 时也可以完整手动使用。

如需启用真实 AI，可以在首页“AI 连接”里直接填写 DeepSeek API Key，Key 只保存在本机浏览器。

也可以改用 `.env` 配置：

```dotenv
DEEPSEEK_API_KEY="sk-..."
DEEPSEEK_MODEL="deepseek-v4-flash"
DEEPSEEK_BASE_URL="https://api.deepseek.com"
```

配置后，AI 会用于任务拆分、今日建议和复盘草稿：

- 收件箱归类建议。
- 今日重点任务建议。
- 每日复盘草稿生成。

AI 输出始终先作为草稿或建议展示，不会代替用户直接决定。

## 10. 5 分钟跑通核心闭环

按下面顺序做一遍，就能验证整个系统是否可用：

1. 在“项目”页新建一个项目。
2. 在“今日”页的“AI 任务生成”区域输入：“下周完成首页设计”，点击“记录并交给 AI”。
3. 查看 AI 拆分结果，点击“一键生成待办”。
4. 将任务挂到刚才的项目下，设置优先级和截止日期。
5. 回到“项目”页，展开项目确认任务已生成。
6. 在“今日”页把这条任务设为今日重点，再标记完成。
7. 到“复盘”页生成并保存今天的复盘。

这条路径跑通后，就形成了“输入 -> 目标 -> 行动 -> 复盘”的日常闭环。

## 11. 本地启动命令

如果你需要在新环境启动这个项目：

```bash
pnpm install
pnpm db:migrate
pnpm dev
```

然后打开：

```text
http://localhost:3000
```

其他常用命令：

```bash
pnpm db:generate
pnpm db:backup
pnpm db:studio
pnpm lint
pnpm build
pnpm start
```

## 12. 当前版本边界

- 单用户本地系统，没有注册、登录和多人协作。
- 没有日历同步、提醒通知、重复任务和浏览器插件。
- 当前版本通过项目树管理任务，未提供独立的全局任务筛选页。
- 删除操作没有回收站，删除前会要求确认。
- 数据库使用 SQLite，适合单机或单实例部署，不适合多实例共享写入。

建议先真实使用一周：每天记录至少一条内容，24 小时内清掉待处理收件箱，并完成至少三次复盘，再根据使用感受决定下一步迭代方向。
