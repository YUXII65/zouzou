# 小程序提审检查清单

> 用途：每次提交微信审核前，从头到尾过一遍。
> 用法：先跑 `pnpm check:review`（机器能查的一次跑完），再人工过第 2、3 节。
> 别把「脚本全绿」当成「审核必过」——脚本覆盖不到的写在最后一节。

## 0. 一条命令跑完自动检查

```bash
pnpm check:review
```

它按顺序跑：`typecheck` → `lint` → `test` → `verify:miniprogram` → `check:online`，
再额外检查 `apiBase` / `appid` / 主包体积 / 页面文件完整 / `require` 的模块是否存在 /
`miniprogram/` 里有没有「本地有、git 没有」的文件。

结果里出现 `RISK` 或 `FAIL` 就先处理，别直接提审。`note` 是提醒，需要你确认。

## 2. 平台侧硬门槛（脚本查不到，只能本人确认）

这几条任何一条没配好，提审都会被挡在门外，而且不会给出「代码问题」这种明确提示。

- [ ] **小程序备案已完成**。微信公众平台 → 设置 → 基本设置 → 小程序备案。2023 年 9 月起未备案不能上架。
- [ ] **域名 ICP 备案已通过**。腾讯云备案控制台看状态；`.WORK` 后缀可备案，管局审核上海市 5-10 个工作日。
- [ ] **request 合法域名已加 `https://nextstep9.work`**（不带路径）。开发管理 → 开发设置 → 服务器域名。
      自检：`config.js` 的 `cloudEnv` 为空，真机走 `wx.request`；域名没备案或没加白名单，真机所有请求都会失败。
      `urlCheck: false` 只对开发者工具有效，真机不认。
- [ ] **服务类目**：「工具 > 效率」这类不需要前置审批的类目，别选到要资质的。
- [ ] **《用户隐私保护指引》与实际采集一致**。当前会涉及：登录账号、昵称/头像、用户记录的内容。
      采集了但没写，是常见的驳回原因。
- [ ] **版本号 + 审核备注**。版本号只是上传时手填的标签（上一版是 3.5.0），不代表包里的代码。
      备注里写清审核员怎么体验：从登录开始能给一个可用的测试账号，说明核心路径是「记录想法 → 澄清 → 生成计划 → 今天要做」。

详细的备案到上线流程见 [beian-launch-runbook.md](./beian-launch-runbook.md)。

## 3. 真机走查（用体验版二维码，不是开发者工具模拟器）

上传后在开发者工具点「预览」，用手机扫。本版改动集中在**今日页的澄清交互**，
所以重点走这条路径：

| # | 路径 | 要确认什么 |
| --- | --- | --- |
| 1 | 登录 → 首页 | 能正常登录，不闪退、不白屏 |
| 2 | 首页输入一个新想法 → 提交 | 出现澄清卡片，不是直接给答案 |
| 3 | 澄清卡片 | 选项能点、选中态明显；「想自己说」能切出输入框并发出 |
| 4 | 多选题 | 能多选，「确定」后正确提交；重复点不会重复提交 |
| 5 | 澄清至少 2 轮后收口 | 生成计划卡（不是中途就出任务） |
| 6 | 确认计划 | 任务出现在「今天要做」 |
| 7 | 任务标完成 | 变终态，按钮禁用，不能点回待办 |
| 8 | 文件页 | 能展开；长期项目「进入下一阶段」可用 |
| 9 | 个人页 | 夜间模式切换、退出登录正常 |
| 10 | 弱网 | 断网时按钮不会永远停在「处理中」（AI 请求总预算 26s） |

第 3、4 条是本版新改的，最容易在真机上出问题，别跳。

## 4. 提交动作

1. 微信开发者工具打开 `miniprogram/`（路径见 [private/local.md](./private/local.md)，仅本地）。
2. 「上传」→ 填版本号和项目备注。
3. 微信公众平台 → 管理 → 版本管理 → 提交审核（CLI 没有这个命令，只能网页后台做）。
4. 审核通过后手动「发布」——**上传 ≠ 上线**，只有发布后用户才用得到。
5. 发布后自检：在小程序列表里删掉「走走」再重新进入（有缓存），确认底部署名是新版本。

## 5. 这份清单覆盖不到的地方

写清楚边界，避免「检查过了」变成盲目自信：

- **审核是人工 + 政策判断**，类目、隐私、AI 生成内容合规都可能被驳回，脚本无法预测。
- **AI 输出本身是随机的**。脚本只保证链路能跑通（189 个用例 + 提示词门禁），不保证每次生成的话术都合适。
- **平台侧配置不在仓库里**：备案状态、服务器域名白名单、隐私指引，只能去后台看。
- **真机差异**：机型、微信版本、网络环境，模拟器全绿不代表真机没问题。
- **证书有效期**：EdgeOne 证书 23 天内到期，属于外部状态，脚本只能告诉你还剩几天。

结论：这份清单能保证**已知的机械故障都被排除**，不能保证审核一定通过。
遇到驳回，先看驳回理由属于上面哪一类，再决定改代码还是改后台配置。
